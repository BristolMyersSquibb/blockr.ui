2Questions

B1The vocabulary: how many kinds, told apart by what

.tk-pill is a static status, .jscf-pill a column you click to open its card, .ctrl-receipt-chip a read-only value and .pp-ctrl-chip a checkbox. Today the name says nothing about the job, and most of them share one shape (4px, grey fill, 1px border), so a package name, a picked value and a toggle look alike. Both panels below hold the same content.

A. Four kinds, by what a click does

Badge describes something, no click. Tag is a value (a column, a level, a condition); it has a × when it can be removed. Pill changes a setting on click (choice-controls part). Count is a number on a control. Plus the status dot.

B4When a badge may have colour

Colour is used for four different things today: status (io path, tile), "on" (crossfilter "Added"), a hue per data type (crossfilter Categorical purple, Numeric green, Date amber), and ranks of a p-value (broom, Bootstrap solid badges in blue, teal and grey). Purple and teal are not in the palette.

A. Status and "on" only

Neutral by default. Accent tint = on, added, cutting rows. Danger, warning, success tints = a result the user must know about.

B6Tags: the × at rest

3Recorded as they are

  • Tag geometry: 13px text, 4px corners, 1px border-default, bg-hover fill. The select tag and the crossfilter "Filter by" pills share it; the crossfilter's comment names .blockr-select__tag as its model.
  • Accent tint on a tag means the value is cutting rows (.jscf-pill--filtering), at the main button's 7% fill and 35% border.
  • The "+N" overflow stands in for hidden tags: tag geometry, accent tint, a click expands the field.
  • Block status is an 8px dot on the block icon with a 2px ring, one spec for dock and DAG (block_status_style()). Its colours become tokens: stale text-muted, waiting border-warning, failed border-danger, the ring bg-surface so it holds in dark mode. Unset uses #eab308, which is not in the palette; it needs a palette step or merges with waiting.
  • Stays text, no chip: column types in the table preview (int, dbl), the chart and table status line and its drill receipt (.dd-status-text, .dd-status-receipt), the filter trail (printed in captions from the dm), the Big N at the end of a column header.
  • Click-to-cycle pills (.blockr-pill in dplyr, dm, viz, ggplot, input; .pp-ctrl-pill, .pp-ctrl-chip; join type, arrange direction, slice mode) are in the choice-controls part.
