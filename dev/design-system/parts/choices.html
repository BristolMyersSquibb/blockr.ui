Proposal: A, checkbox everywhere; no switch in blockr. Every on/off in the code is an option the user sets, and Blockr.checkbox already covers most of them. C2One of two or three fixed values

asc or desc, first or last rows, horizontal or vertical, stacked, grouped or 100%. Today this is a cycle pill, a Select, a segmented control or a switch, depending on the package; viz uses a pill for Orientation and a Select for Order in the same gear. A cycle pill shows one value and hides the rest. The 2026-07-22 rule (Select for any count) came from the picker block, whose options are columns chosen at build time.

Proposal: B, a segmented control for a fixed set of two or three short values. Both values stay in view, the pick is readable without a click, and it fills a grid cell like any field. Three segments need about 240px, so a segmented cell takes a "wide" track, not a "knobs" one. Selected = the tinted accent of the main button. Four or more values, or labels too long for the cell, go to Select. Options that come from the data (columns, measures, levels) stay Select at any count, which is the case the 2026-07-22 decision was made for. This replaces the cycle pills of this kind, the viz Order select, the head block's "Tail" switch ("From: First / Last"), stats' shinyWidgets buttons and the dm/io/pharma segmented copies, and it is the component the ggplot facet wrap/grid strip already is. Runner-up: C.

4Recorded as they are

  • Blockr.Select is the only dropdown: single and multi, bordered (42px) in the grid, bare inside rows, tags removable and draggable. Options show the value first and the label as a muted sublabel.
  • Blockr.checkbox: 16px box, radius 4, accent fill when checked, native input underneath, label names the "on" state. In the grid it sits in a 42px cell with an empty label row (L4).
  • Chart type pickers are icon tiles, with group headings where types are grouped (2026-07-04).
  • Text fields commit on Enter or blur with the Enter ↵ chip armed while dirty; Escape reverts (2026-07-02). dplyr's 30px/radius 6 inputs in separate, unite, pivot and bind-rows move to the 42px field.
  • Title-slot words in a chart subtitle keep their own behaviour: a flag word toggles in place, a list word opens Blockr.Select.menu().
  • Selected state across choice controls is the tinted accent: segment, type tile, pressed icon button, open gear.
