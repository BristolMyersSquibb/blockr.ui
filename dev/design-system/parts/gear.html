Gear

Builds on: buttons (26px header size, the tinted "main" style), the layout part (header row, section titles, params grid), "every configurable option is in the gear", "no gear when a block has no options". One correction to the brief: the chart block's expose band (2026-09-08) was retired on 2026-09-09 (blockr.viz 5fd51f1, "the sentence is the only channel"). A chart argument reaches the block's face as a slot in its subtitle sentence now, per blockr.docs/design-system/pinned-controls.md. G6 assumes that.

G6What stays on the face, and what simplified mode leaves

"Every option is in the gear" is decided. How much of it also sits on the face differs by family: dplyr keeps a block's main fields on the face and puts extras in the gear; viz keeps everything in the gear and hands a reader the words of the subtitle sentence. Simplified mode hides the gear only, so this split decides what a reader can still change. The patient profile's gear holds reader view toggles (Timeline, Pre-treatment, Value lines), and dock's rule does not reach it.

Proposal: A, written down as the rule. A transform block's face holds the fields that define it and the gear holds the rest; an output block's face holds the output and its sentence, and the sentence's slots are the only way to put one of its arguments on the face; its gear keeps a row for every argument, slotted or not. 2Recorded as they are

  • No gear when a block has no options, including per mode: stats broom on glance, dplyr slice, io formats with no options.
  • The gear is the last item on the right of the header row; its band opens directly under that row, above the face's controls.
  • Changes in the band apply as they are made. Text fields commit on Enter or blur with the "Enter" chip; code commits on Run (code and function blocks) or the Apply chip (chart prepare script). No band has an Apply button.
  • The band shrinks with the block and never scrolls sideways; under 404px of band width the chart's sections drop to one column (settings-band.css).
  • Hiding the gear in simplified and locked mode is dock's job, done with one CSS rule on the gear's class; blocks never ask which mode they are in.
