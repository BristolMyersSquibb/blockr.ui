Special blocks: crossfilter, charts, code

Builds on: the three text levels and 12px muted labels; the four button kinds at 42/30/26; small icons shown on hover, remove turning red; the anatomy, section titles (Q1) and output title (Q3) of block-layout.html; the 26px gear canon; the dark tokens. Data colours live in blockr.theme and are only located here, not discussed.

Three blocks draw most of their own UI: the dm crossfilter (DOM built in JS), the chart (ECharts on a canvas, with HTML titles and legend around it), and the CodeMirror editor shared by the code, function and composer blocks. For each, this part separates what must follow the core system from what stays special. Six questions.

2Questions

S1Text on the chart canvas: one mark size, or the type scale?

The type scale is 12, 13, 14, 16 and 20. Inside the plot the chart uses 10, 11, 12 and 14: axis labels and names at 11px, data labels at 10px, treemap labels at 12px, tooltip text at 14px, the legend at 11px. The 11px is load-bearing: chart.js measures the category gutter at 11px and budgets 14px per label row before it thins labels. The printed charts (static_chart()) are authored at the same 11px (8.25pt) and scaled per medium by gg_type_scale().

3Recorded as they are

Follows the core system (decided rules applied, no question left)

  • Field labels in the code and function params grid and the viz mapping band: 13px/500 becomes 12px regular muted (block-layout Q2).
  • Chart, table and composer titles follow block-layout Q3; subtitle 13px muted; caption 12px muted and italic in all three today, kept italic.
  • Header tools: the chart's and composer's 30px gear, download and search buttons go to the 26px canon; the crossfilter gear is already 26px.
  • "Reset all" is already the main button at 26px (accent tint 7%, border 35%). Its count badge is text-on-accent on bg-accent.
  • Crossfilter pills: 13px tags; a filtering pill wears the main button's accent tint (accent-subtle fill, 35% accent border, text-accent).
  • Editor footer buttons: Run and Accept all become main at 26px; Reject all becomes secondary, since it restores the previous code and deletes nothing. The green and red two-tone badges and the 24px height go. The syntax message uses text-danger (its fallback today is Bootstrap's pink #d6336c).
  • Composer's busy line and "composed in" time: text-muted (today text-secondary, and grey-400 at 0.7).
  • Slots: .blockr-slot (accent, 500, dashed underline, solid on hover) and .blockr-slot-offer are declared identically in blockr.viz chart.css and blockr.dm crossfilter-block.css, and both files say they move to blockr.ui. They move as one rule; the hover colour reads accent-700 through a token.
  • Marks: --blockr-mark-radius (2px, value end only) is read by the crossfilter bars and the rank table and matched by a literal in chart.js; --blockr-mark-weight-supporting (0.6) marks bars that support a choice, today only the crossfilter's. Both are in blockr-tokens.css.
  • Focus: viz's 0.45 ring (--blockr-color-focus) on legend chips and the gear becomes --blockr-focus-ring.

Stays special

  • Crossfilter: the dense rows, the count column sized per card (--jscf-count-w), the range card with its density curve and two-thumb slider, the inverse value bubble while dragging, and the two floating bands (block settings from the gear, "Add custom filter" from the pill row).
  • Chart: everything inside the plot is drawn by ECharts and reads CSS only at render; the 25 x 14 legend swatch; the drill flash and pulse and the fading status receipt (chart.css).
  • Data colours: blockr.theme palettes, with the fallbacks in chart.js and R/theme-palette.R (they disagree; left as is, 2026-09-14). Block category colours: Okabe-Ito through blk_color() in blockr.dock, fixed under every theme.
  • Code editor: the monospace face (--blockr-font-mono), line numbers, the input-line band and gutter glyphs of the code block, and the green and red line backgrounds of an AI review diff, which are diff meaning.
  • Composer: the busy cue (after 300 ms the body dims to 0.45 and a clock runs under the sentence), the "composed in" time that fades after 2 s, and the slot input drawn over the word in the word's own type. No other block has a busy cue inside the block; whether they should is not decided here.
