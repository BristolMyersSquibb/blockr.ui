Three open questions

All on realistic block cards: the app's measurements, muted labels, near-black values. Each question has a proposal; "yes to all" works, or name the one you'd change.

1. Small grey icons

Drag handles, remove buttons, fold arrows. Today they are light grey (grey-400), which is 2.5:1 on white. They are controls you can click or drag, so WCAG asks 3:1 for them, like any other part of a control. Only disabled things are exempt.

Proposal: mid grey. One simple rule: light grey means disabled, nothing else. Everything you can read or click is at least muted.

2. Input borders

Field borders are grey-200, 1.2:1 against the white card. For most borders that is fine, they only separate things. For an input the border is its visible edge, and WCAG would want 3:1 there. Most design systems keep input borders soft anyway; the focus state (blue border and ring) marks the field you are in.

3. The typeface

Today every blockr user sees Open Sans: bslib's default theme ships it (bootstrap-5.3.8/font.css). The question is whether to keep it, switch to the system font (San Francisco on a Mac, Segoe UI on Windows), or ship a different font such as Inter.
