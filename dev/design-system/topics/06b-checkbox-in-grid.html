Topic 6b: a checkbox in the field grid

Your point: a checkbox drawn inside a field box is too much ink. There is a second problem in today's version: the checkbox keeps an empty label row so it lines up with its neighbours, and when it wraps to a new row that empty row leaves a gap. Four ways, all in the one grid from topic 6 (a checkbox takes one column). Try the widths.

Panel width
Proposal: C, a bare checkbox with no label row. The box and its words, no field shell: the checkbox is already a control with its own edge, so the shell only adds a second frame. Without the empty label row it still lines up with the inputs beside it, because it sits on the bottom line of the row, and when it wraps to a row of its own it leaves no blank line (compare B at 520px). Runner-up: D, when a section has several on/off options and they read better gathered in one row under a label.
