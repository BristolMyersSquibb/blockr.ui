Topic 22: a focus cue you can see

The one focus style today is --blockr-focus-ring: a 3px ring of the accent at 12%. It is about 1.2:1 against white. A field is fine, because it also turns its border accent. A frameless 26px tool, a segment or a checkbox has only the ring, so a keyboard user cannot see where focus is.

Each drawing shows four things focused at once: the download tool, the field, the "Any" segment and the checkbox. Click into a card and press Tab to see the real thing. Only keyboard focus shows the cue (:focus-visible); a mouse click shows nothing, except on text fields, which always show it. The keyboard row in a menu is not focus (focus stays in the filter box) and keeps the hover look.

Proposal: B, a 2px accent outline, fields keep the ring. The accent is 5.2:1 on white, so focus is visible on every element, and only keyboard users ever see it. The 2px gap keeps the outline off the gear's own frame and off a selected segment's tint. Fields keep what they have, because a field's focus also means "you are typing here" and shows for mouse users too. In tokens: --blockr-focus-outline: 2px solid var(--blockr-color-border-accent) and --blockr-focus-offset: 2px next to the existing ring. Runner-up: D.
