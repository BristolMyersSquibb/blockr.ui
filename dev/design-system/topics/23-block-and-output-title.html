Topic 23: the block title and the output title

Topic 19 cut the block title from 20px to 16px "so a chart block's two titles no longer compete". They now sit about 50px apart at the same size and weight, 16px/600, often with nearly the same words. The dock tab above says the block's name a third time.

The block title names the panel: you rename it there, and it is what the tab, the DAG and the pickers show. The output title belongs to the chart or table: it exports with it and is what a reader reads. A transform block has only the block title. Each option below draws both kinds under their dock tabs.

Q1How big is the block title?

A. Keep 16px/600 for both

Today.

B. Block title 14px/600

The body size, still semibold and in the default text colour. The output title stays 16px and becomes the one heading on an output block.

C. Block title 14px/500, muted

The header reads as the panel's label, like the tab. It turns default on hover, where you would click to rename.

Proposal: B, block title 14px/600. On an output block the output title leads, and the header steps back one size without looking disabled. On a transform block 14px/600 is still the largest text in the panel (labels and section titles are 12px), so it keeps working as the heading there. C makes a transform block's only heading muted, and muted text is for labels. Runner-up: C.
