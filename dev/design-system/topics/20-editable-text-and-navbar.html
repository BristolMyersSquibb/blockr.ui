Topic 20: renaming things, and the navbar

Two parts. First every place a name is edited in place, captured from a running board (blockr.outline first-workflow, blockr.dock feat/simplified-mode, blockr.session): four places, four ways. Then the navbar, read against the design system.

Part 1: renaming in place

Block title (blockr.dock block_card_title()). Hover: a 2px dashed ring and a pencil. Click: a text input with a 2px dashed border at the title's 20px. The input's own label ("Block name") shows above it and overlaps the old title, which is a bug. Enter or blur commits.

Outline row (blockr.outline outline-rail.js). Double-click the name, or "Rename" in the row's menu: the name becomes editable in place (contenteditable); the row takes a blue focus edge. No field look.

View name (blockr.dock view-binding.js). A pencil in the view menu swaps the name for a small input (2px 6px, accent border, its own 2px ring). Empty and duplicate names are refused with a message.

Workflow (blockr.session). No rename: at the first save a modal asks for a "Workflow ID" (a generated one, "Must be unique"); after that the navbar shows the ID in monospace. The board's display name is a separate board option, set in Board options.

Part 2: the navbar

Today, unsaved and saved (blockr.session project-navbar.css, blockr.dock blockr-dock.css): logo; the workflow ID in monospace; "Not saved" / "Just now"; save as a split button; "+ New" as a split button; on the right an avatar, a status circle, the view menu ("Build") and the board options gear.

Measured against the design system:

  • Colours are literals. blockr.session's navbar CSS writes #333, #555, #999 and hsl(220, 3%, …) greys, so it follows neither a theme nor the dark scheme. "Not saved" is #999, 2.8:1, below the text minimum.
  • Three heights. Save and New are 28px, the dock's icon buttons 32px, the avatar 32px; the toolbar size is 30px.
  • Two split buttons side by side (save and New), each with a caret; the system has no split button.
  • Hover on the dock's navbar icons is grey-300 (the strong border colour) instead of bg-hover.
  • The avatar is a purple gradient, off the palette.
  • The view menu marks the current view with a blue fill; the decided current pick is weight 600 (M2).
  • The spinner's label is a dark inverse tooltip; tooltips are light cards.
