Topic 25: column names and their labels

Pharma data carries a label on every column: AGE is "Age", TRTEMFL is "Treatment Emergent Analysis Flag". The design system says one thing about it (Select options show the name, then the label as muted meta text). The packages do three different things. Pickers, the table preview, the crossfilter and the flag filter show the name first with the label after it; the flat table shows the name with the label under it. Charts, summary and structured tables and the xlsx/pptx exports show the label only. Receipts, the filter trail and the crossfilter's shelf pills show the name only. The label itself comes in five styles (grey-400 or grey-500, 11, 12 or 13px, 4 to 8px gaps) and six separators (none, " — ", " (…)", ": ", " / ", " · ").

Set without a question, because every option below needs them (say so in a note if one is wrong):

  • One look for a label next to a name: 13px text-muted, 8px after the name, no separator, cut first when space runs out; in a tag 12px. Under a name (a table header) it is its own line at 12px text-muted.
  • No label, or a label equal to the name: the name alone. Never "unset", never "AGE AGE".
  • One reader for every package: attr(x, "label", exact = TRUE), a single string or nothing. Without exact, a column with haven value labels returns those and several readers error (in the inbox).
  • A tooltip that shows both reads AGE · Age.

Proposal: A, name first, label as meta, everywhere a column is picked. The name is unique and short, it is what the code, the expression field and the filter trail use, and people who work with ADaM know TRTEMFL better than its label. The label still helps to find and to confirm, so it stays beside the name and is cut first. B makes rows and tags long and puts the part that is cut last in front. C hides the label on exactly the tags and rows where it confirms the pick. Runner-up: C.

Proposal: B, follow the surface. It is the rule from Q1 and Q2 applied to text: the board speaks in names, the exhibit in labels. A reader of a printed table sees "Age" in the header and "Age" in the caption. The cost is length: a long label makes a long caption. Runner-up: A, if captions should stay as compact as they are.

Q4Code and decode pairs: PARAMCD and PARAM

The same pattern one level down, in the values: ALB is "Albumin (g/L)". Only blockr.pharma pairs them today, in five ways: chips show the decode, card titles lead with the code, grid subtitles print "ALB — Albumin (g/L)", bands print "label · PARAMCD".

A. The same rule as names and labels

Picking: code first, decode as meta. An exhibit: decode only, code in the tooltip.
