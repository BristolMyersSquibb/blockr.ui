Font files for the design-system pages in `dev/`, so a comparison never
depends on a network download or on what a machine has installed.

- `inter-latin.woff2`: copied from `blockr.theme/inst/fonts/`. Inter, SIL Open
  Font License 1.1.
- `open-sans-latin-{400,500,600}.woff2`: the Latin subset from Google Fonts
  (Open Sans v44). SIL Open Font License 1.1.

Development only; `dev/` is excluded from the package build.
