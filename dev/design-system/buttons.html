A separate discussion, as you said. First every button style in the packages today, then five options for the main button in three real situations, then a proposed system. Everything is in Open Sans.

2Five options for the main button

Same three situations in each column: a dialog footer, a write block, and a block's header strip with a reset. Secondary and ghost buttons are the same everywhere; only the main button changes. Hover them.

A. Solid accent

Today's btn-primary. The strongest; the one you find too stark.

B. Tinted

The crossfilter reset, scaled up: accent text, 7% fill, 35% border.

C. Soft solid

Pale accent fill, darker accent text, no border.

D. Near-black

Neutral solid, as in Linear or Vercel. Strong without colour.

E. Outline

Accent border and text on the surface.

3Proposed system

Three kinds and three sizes, with B as the main button. The sizes follow the control heights that already exist: 42 beside inputs, 30 in toolbars, 26 in a header strip next to the gear.

42 · beside inputs30 · toolbars, dialogs26 · header strip, next to the gear Maintinted accent; one per view Secondarysurface, soft border Quiettext only, muted Destructivetinted red, only to confirm Disabled
Proposal: B, tinted, as the main button everywhere; no solid accent button in blockr. It is the style the production boards already use for reset, it follows a theme's accent and dark mode through one token, and three existing copies collapse into one. Secondary moves from grey fill to surface with a soft border, so it sits quieter than the main button instead of competing with it. Quiet replaces the grey-400 text links, which fail contrast. Runner-up: C, if B reads too light in a dialog.

Not on this page: the click-to-cycle pills (>=, AND, desc). Whether a choice is a pill, a select, a checkbox or a toggle is the next discussion, together with badges.
